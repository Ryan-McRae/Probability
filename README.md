# Probability & Stochastic Processes — Study Notes & Solutions

A personal study repository revisiting ***Probability and Stochastic Processes*** by **Roy D. Yates and David J. Goodman**, containing worked solutions to selected end-of-chapter problems (including code where helpful) alongside my own study notes and derivations.

## Background & Motivation

I'm a junior software engineer working heavily with survey data, which has deepened my interest in working with data more rigorously. Combined with a strong interest in quantitative/algorithmic finance and machine learning, I decided to go back to foundational probability to build a sharper, more intuitive grasp of random variables, distributions, and stochastic processes.

I first encountered this text during my BEng in Electrical and Electronic Engineering at **Stellenbosch University**. While I always found the subject fascinating, I felt I could have mastered it much more deeply the first time around, so this repo is both a skills refresher and a clean slate to build real fluency from first principles.

## Authorship & AI Usage

All mathematical derivations, explanations, written reasoning, and code in this repository are my own work—**AI was not used to generate solutions or explanations**. Where AI (Gemini) was used, it was strictly for formatting Markdown text (such as structuring this README).

## How I Use This Repo

- **Notes (`notes/`):** Jupyter notebooks focused on *why* a result holds, edge cases, and connections to survey data analysis, statistical modeling, and time-series / financial data.
- **Solutions (`solutions/`):** Jupyter notebooks with step-by-step derivations, assumptions, sanity checks, and Python/code implementations or simulations where useful.
- **Assets (`assets/`):** Supporting visual aids and figures used across notebooks.
